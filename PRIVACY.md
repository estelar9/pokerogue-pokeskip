# Politique de Confidentialité / Privacy Policy — PokéSkip

*Dernière mise à jour : 1er octobre 2026 / Last updated: October 1, 2026*

---

## 🇫🇷 Version Française

### 1. Introduction
PokéSkip est une extension de navigateur open-source et un outil d'assistance pour le jeu web [PokéRogue](https://pokerogue.net/). Nous accordons une importance primordiale au respect de votre vie privée. Cette politique explique comment l'extension fonctionne et garantit qu'aucune donnée personnelle n'est collectée.

### 2. Collecte de données : Zéro collecte
**PokéSkip ne collecte, ne transmet, ne stocke et ne vend AUCUNE donnée personnelle ou sensible.**
* Aucun identifiant personnel (nom, e-mail, adresse IP) n'est recueilli.
* Aucun historique de navigation n'est enregistré ni surveillé.
* Aucun outil d'analyse, de télémétrie ou de pistage tiers (ex. Google Analytics) n'est intégré.
* Aucune donnée n'est envoyée vers un serveur externe.

### 3. Données stockées localement
Toutes les données manipulées par PokéSkip restent **exclusivement sur votre appareil**, dans l'espace de stockage local de votre navigateur (`localStorage`) :
* **Préférences & Paramètres** : Options d'affichage des notifications, réglages de vitesse, mode de remplacement automatique.
* **Règles de jeu** : Vos choix de capacités à ignorer ou à remplacer pour chaque espèce de Pokémon.
* **Statistiques locales** : Compteur d'attaques passées automatiquement au cours de vos sessions.

Ces données ne quittent jamais votre machine. Vous pouvez les réinitialiser ou les supprimer à tout moment directement depuis l'onglet « Paramètres » de PokéSkip ou en vidant les données de votre navigateur.

### 4. Utilisation des autorisations
* **`activeTab`** : Utilisée uniquement lorsque vous cliquez volontairement sur l'icône de l'extension pour afficher les statistiques locales dans la fenêtre contextuelle (popup).
* **`scripting`** : Permet à la fenêtre contextuelle de lire le nombre d'attaques ignorées dans la partie en cours pour l'afficher sur le popup.
* **Accès aux hôtes (`*://pokerogue.net/*`, etc.)** : Nécessaire exclusivement pour injecter l'interface d'aide en jeu (table des types, raccourcis, avance rapide des dialogues).

### 5. Code tiers et sécurité
PokéSkip ne charge aucun code exécutable distant. L'intégralité du code source est auditée, open-source et hébergée publiquement sur GitHub.

### 6. Contact
Pour toute question concernant cette politique ou le fonctionnement de l'extension, vous pouvez ouvrir un ticket sur le dépôt officiel :  
👉 [https://github.com/estelar9/pokerogue-pokeskip/issues](https://github.com/estelar9/pokerogue-pokeskip/issues)

## 🇬🇧 English Version

### 1. Introduction
PokéSkip is an open-source browser extension and Quality-of-Life assistant for the web game [PokéRogue](https://pokerogue.net/). We are strongly committed to user privacy. This policy outlines how the extension operates and guarantees that no user data is collected.

### 2. Data Collection: None
**PokéSkip does NOT collect, transmit, store, or sell any personal or sensitive user data.**
* No personal identification information (name, email, IP address) is gathered.
* No browsing history or activity is recorded or monitored.
* No third-party tracking, analytics, or telemetry scripts (such as Google Analytics) are embedded.
* No data is ever transmitted to any external server.

### 3. Locally Stored Data
All data processed by PokéSkip remains **strictly on your local device**, stored inside your browser's local storage (`localStorage`):
* **Preferences & Settings**: Notification display toggles, duration settings, automatic replacement mode.
* **Gameplay Rules**: Your configured move-skip and move-replacement rules per Pokémon species.
* **Local Statistics**: Total count of moves skipped during your play sessions.

This data never leaves your computer. You can delete or reset this data at any time via the PokéSkip Settings tab or by clearing your browser cache.

### 4. Permissions Justification
* **`activeTab`**: Used only when clicking the extension icon in the toolbar to display session statistics in the popup window.
* **`scripting`**: Allows the popup window to retrieve local counters from the active PokéRogue tab.
* **Host Permissions (`*://pokerogue.net/*`, etc.)**: Required solely to inject the in-game UI overlay (type matchup chart, shortcut handlers, dialogue auto-advance) onto the game canvas.

### 5. Third-Party Code & Security
PokéSkip does not load or execute remote code. All source code is fully open-source and auditable on GitHub.

### 6. Contact
If you have any questions about this privacy policy, feel free to open an issue on the official GitHub repository:  
👉 [https://github.com/estelar9/pokerogue-pokeskip/issues](https://github.com/estelar9/pokerogue-pokeskip/issues)
